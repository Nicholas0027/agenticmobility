# Agentic Mobility

The project site of **AgMSim**, the Agentic Mobility Simulator: a testbed for mobility systems in which
every participant can be an agent (travellers, their cars, on-demand cars, transit, charging stations,
traffic lights and the orchestrator of the network).

- **Site, with the simulator running in the page:** <https://nicholas0027.github.io/agenticmobility/>
- **Source code of the simulator:** <https://github.com/Nicholas0027/AgMSim>

This repository only serves the site (branch `gh-pages`). Its pages are written in `website/` of the AgMSim
repository and published from there with `sh website/publish.sh`.
